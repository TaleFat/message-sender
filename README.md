# Message Sender

Windows-приложение для периодической отправки сообщений.

## Скачать

Скачайте `MessageSender.exe` из раздела [Releases](../../releases).

## Запуск

Запустите `MessageSender.exe` двойным нажатием.

## Возможности

- настройка интервала отправки;
- настройка текста сообщения;
- тёмный интерфейс;
- горячая клавиша запуска и остановки;
- режим отправки через окно Discord;
- режим Discord API для бота.
